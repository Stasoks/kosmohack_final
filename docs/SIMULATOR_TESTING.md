# Проверка factory simulator

## Автоматические короткие тесты

```bash
pytest factory_simulator/tests -q
```

Они проверяют детерминированную state machine, P0 payload-модели, отсутствие `source.sequence` и сохранение дефекта до успешного повторного контроля.

## Smoke после запуска demo stack

```bash
bash scripts/local_smoke.sh
bash scripts/simulator_smoke.sh
```

Smoke создаёт одну краткую сессию штатного режима и ждёт её завершения не более 20 секунд.

## Ручная проверка human-in-the-loop

1. Создайте режим **Дефект и доработка** и запустите его.
2. Дождитесь состояния **Ожидает решения контролёра**.
3. В разделе **Контроль качества** подтвердите несоответствие и назначьте доработку.
4. Вернитесь в симуляцию: поток должен выполнить связанную доработку и повторный контроль.
5. В **Контроле качества** подтвердите успешную проверку доработки.
6. Симуляция должна продолжить закреплённый маршрут и завершить изделие.

Проверьте в истории изделия, что решение контролёра находится между дефектным контролем и началом доработки, а верификация — после повторного контроля.
